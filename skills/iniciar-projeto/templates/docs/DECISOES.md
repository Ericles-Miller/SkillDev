# Decisões

Toda decisão técnica ou de produto que não estava nos docs entra aqui, com a data e onde foi tomada. Assim ninguém decide de novo o que já foi decidido, e ninguém precisa lembrar de cabeça.

Formato: `- **DD/MM/AAAA — <tema>:** <o que foi decidido>. <por quê, e a alternativa descartada>. Ver <task ou doc>.`

Uma decisão grande (arquitetura, provedor, modelo de dados, padrão que outras tasks seguem) também ganha um ADR em `docs/decisoes/`. Aqui fica só a linha, com o link para ele.

- **DD/MM/AAAA — Regras do projeto:** <git, branches, cobertura de testes e fonte de verdade, como estão no CLAUDE.md>. Ver `CLAUDE.md`.

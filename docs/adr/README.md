# Decisões do SkillDev (ADRs)

Cada arquivo registra uma decisão sobre como este repositório funciona: o contexto, o que foi decidido e as consequências. Antes de mudar uma regra, leia o ADR dela para saber por que ela existe. Decisão que muda não se edita: um ADR novo substitui o antigo, e o antigo ganha "Substituído pelo NNNN".
